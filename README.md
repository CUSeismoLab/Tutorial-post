# CUSeisTut

The CUHK Seismology Lab tutorials, rebuilt with Astro and Starlight. The original English course material is maintained as editable MDX, with KaTeX mathematics, syntax-highlighted code, full-text search, and the original downloadable teaching resources.

## Run locally

Use Node.js 24 (or Node.js 22.23.4 or newer).

```sh
nvm install
nvm use
npm ci
npm run dev
```

Open the local address printed in the terminal (normally `http://localhost:4321`).

```sh
npm run check
npm run build
npm run verify
npm run preview
```

Search uses the index generated by the production build. Use `npm run preview` to check the complete production search experience.

## Edit the website

- `src/content/docs/index.mdx`: homepage metadata and hero.
- `src/components/CourseCatalog.astro`: homepage course links and descriptions.
- `src/content/docs/<chapter>/index.mdx`: course chapters. Keep each chapter's explicit `slug` stable when editing.
- `src/content/docs/intro/git-update.mdx`: original contribution guide.
- `astro.config.mjs`: course sidebar, site metadata, and rendering configuration.
- `src/styles/custom.css`: site styling and responsive homepage layout.
- `public/media/`: original images, notebooks, scripts, waveforms, PDFs, and archives, retaining their source directory structure.

Use normal Markdown, fenced code blocks, `$...$` for inline equations, and `$$...$$` for display equations. Starlight `:::note`, `:::tip`, and `:::caution` blocks are available for callouts. Local document links use `/chapter/` and local assets use `/media/chapter/file.ext`; the build adds the deployment base path automatically, including on MDX image elements.

## GitHub Pages

The site is fully static. The included workflow builds and publishes changes to `main` once this folder has been pushed to a GitHub repository and **Settings → Pages → Source → GitHub Actions** is enabled. No remote repository or deployment is created by this local migration.

The workflow automatically derives the site URL and repository base path. For a custom domain, set the repository variable `SITE_URL` to the full origin (for example, `https://docs.example.org`), configure the domain in GitHub Pages, and optionally add `public/CNAME`. `BASE_PATH` defaults to `/` with a custom domain; override it using a repository variable if needed.

To verify a project-subpath build locally:

```sh
SITE_URL=https://example.github.io BASE_PATH=/cu_docs npm run build
BASE_PATH=/cu_docs npm run verify
BASE_PATH=/cu_docs npm run preview
```

Open `/cu_docs/` on the preview server. Run `npm run build` again to return to a root-path build. The default site URL is localhost until a production `SITE_URL` is configured.

## Migration and provenance

Original source: `../../cuseistut/docs/source` from this project directory, in the separate local `cuseistut` checkout. The original project is [JunhaoSong/cuseistut](https://github.com/JunhaoSong/cuseistut), published previously on [Read the Docs](https://cuseistut.readthedocs.io/).

All 21 non-homepage RST documents have MDX counterparts. The original homepage is represented by the new course homepage, retaining the lab attribution and useful links. The complete older GMT chapter and original contribution guide are retained under Resources. Scientific examples and their historical software versions are preserved; this migration does not update their algorithms or dependencies.

The migration report records source counts, normalization, and any original-source issues. `scripts/migrate_rst.py` is the one-time conversion tool; it requires Python and Pandoc (or `pypandoc_binary`). Re-running it overwrites migrated chapters, so use the MDX files directly for ongoing editing. `scripts/audit_source_assets.py` checks copied assets against a local source checkout. Neither tool is required for normal website development or deployment.

Original authors and project support are credited on the Acknowledgement page. The original GPL-3.0 license is retained in `LICENSE`.

### Known source issues

Two external illustrations in the ambient-noise chapter (`crossc.jpg` and `antiii.jpg`) were hosted at `volc_seis_commission.leeds.ac.uk`, which could not be resolved during migration. Their original captions and source links are retained with an availability notice. The other five unique external image URLs were reachable when checked. All local teaching assets are present.
